1. **Critical — gold can encode the wrong task outcome.**  
   [tasks.jsonl:37](~/Documents/GitHub/Thesis-wt-distill/sft/data/distill/s2a/tasks.jsonl:37), task `0103`, requests copying a file from `contracts` into sibling directory `vendors`. Gold executes `cp(..., destination='vendors')` while inside `contracts`. The backend creates a **file named `vendors` inside contracts**. Training [row 273](~/Documents/GitHub/Thesis-wt-distill/sft/data/distill/mlx-t1/train.jsonl:273) teaches that action; row 274 teaches stopping afterward. `validate()` checks gold against itself ([distill_tasks.py:291](~/Documents/GitHub/Thesis-wt-distill/benchmark/distill_tasks.py:291)), so this passes. **Fix:** quarantine this task and audit every retained task’s requested outcome against its actual gold state. Add independent semantic assertions, especially for filesystem destinations.

2. **Important — episode acceptance does not establish correct next-step targets.**  
   [distill_rows.py:47](~/Documents/GitHub/Thesis-wt-distill/benchmark/distill_rows.py:47) exports every parsed decision from accepted episodes. I traced **23 exported targets across 21 episodes** that produced tool errors: **21 train, two valid**. Examples include guessed filenames and forbidden `../vendors` destinations. The stock checker permits extra calls and matches gold responses against accumulated results; invocation-order checking is disabled. It supports outcome screening, not “every decision is right.” **Fix:** exclude failed-action targets and audit argument grounding/dependencies at each decision. Preserve recovery contexts only with correct subsequent targets.

3. **Important — grounding and contamination claims exceed the implemented checks.**  
   [distill_tasks.py:467](~/Documents/GitHub/Thesis-wt-distill/benchmark/distill_tasks.py:467) treats the entire tool documentation as grounding, skips small numbers/short strings, and removes file extensions. This cannot guarantee every specific value was stated or retrieved. The exclusion checker ignores numeric literals and only reports string overlap ([distill_exclusions.py:210](~/Documents/GitHub/Thesis-wt-distill/benchmark/distill_exclusions.py:210)). **Fix:** distinguish documented enums/backend constants from task-specific values; persist a reviewed literal-overlap report. The 8-gram/0.85 thresholds are reasonable conservative screens, not proof against semantic copying.
